          Dicoba berurutan bila Endpoint tidak menjawab (pisahkan dengan koma,

          Tidak menjalankan atau mengunduh model di laptop. Pastikan mesin

          Ingatan otak eksternal
          
    
            Ambil konteks proyek dari ingatan pribadi sebelum bekerja. Sambungan
            MCP tetap perlu persetujuan saat dipakai.
          
    
          Perlu "Gunakan ingatan" juga. Potongan permintaan (maks. 500 huruf,
            rahasia disensor) dikirim ke server otak eksternal untuk mencari catatan.
            Catatan yang cocok hanya dikirim ke model lokal (server rumah), kecuali Anda
            izinkan penyedia di bawah.Kimi, Gemini, DeepSeek dan RunPod terkunci sampai ketentuan
            penggunaan data mereka dikutip.
        
    
        
    
          Harga model
          
    
            USD per 1 juta token. Harga bawaan sudah disahkan dan bersumber.
            Harga yang Anda isi menimpa bawaan untuk model yang sama. Model
            berbayar tanpa harga ditolak agar pagu biaya tetap berlaku.
            Kosongkan kolom cache untuk memakai harga input.
