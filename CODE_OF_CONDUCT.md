# Code of Conduct

We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcome newcomers (including people writing in Bahasa Indonesia or English as a
second language), critique code rather than people, and never share anyone's private data.

Report problems to **fahmiwol@gmail.com**. Reports are handled privately.
